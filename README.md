# Blue Bayou Restaurant & Oyster Bar

Website and owner dashboard for Blue Bayou, 717 Canal St, New Orleans. Built by Studio 1801.

- `index.html`: the website (menu, pickup ordering, live music, parties and catering). The dashboard also opens at `/#dashboard`.
- `dashboard.html`: the owner dashboard at `/dashboard` (orders, party and catering requests, music lineup, menu, hours and details).

Both are single self-contained files with no build step. Data syncs between the site and dashboard in the same browser. Syncing across devices needs a shared backend (planned).
